Your AI coding agent,
remote-controlled from the phone

Prompter pairs the OpenCode TUI in tmux with a native Android app: dictate prompts by voice, watch the agent work on a live color mirror of the terminal, switch sessions, get notified when the build of your dreams is done — from the couch or from another city.

No account, no cloud, no telemetry. Your LAN — or your private Tailscale network.

Everything the keyboard does — minus the keyboard

A bridge on the laptop injects keystrokes into tmux and streams the pane back. The app is the front-end your couch deserves.

🎙️

Voice input

Dictate a prompt, edit it if the recognizer misheard, hit Send. Quicker than typing on a TV remote.

🖥️

Live color mirror

The actual terminal pane — truecolor, bold, gradients — streamed to the phone. Wrap mode, zoom, scrollback history on demand.

🗂️

Session tabs

See every OpenCode session with unread markers and jump between them with one tap. No blind Alt+arrow counting.

⚡

Macros & keys

Every key you need — arrows with auto-repeat, Ctrl+P palette, Esc-interrupt — plus your own one-tap command macros.

🔔

Notifications

Fire a task, pocket the phone. Prompter pings you the moment generation finishes or the agent needs a decision.

🌐

Internet via Tailscale

Away from home? A private WireGuard tunnel connects you anywhere — without exposing a single port to the internet.

Up in two minutes

Any Linux distro, no root required. The installer sets up a systemd service, generates a token and prints a QR code.

Install on the laptop

Clone and run the installer — it checks dependencies, creates a venv and enables prompter.service.

Scan the QR code

prompter qr shows a code with host, port and token. The app scans it — no typing 64-hex tokens by hand.

Talk to your agent

Install the APK, point the camera at the QR, and the pult connects. Uninstall any time with uninstall.sh.

# 1 · install (any distro, no root)
$ git clone https://github.com/L105HA/prompter && cd prompter
$ ./install.sh

# 2 · start and show the QR (LAN + Tailscale)
$ prompter start
✓ bridge healthy on :8788 ✓ tmux session 'opencode' ✓ tailscale up
$ prompter qr

Terminal purists: prompter attach opens the OpenCode TUI locally whenever you want the real keyboard back.

Private by design

The bridge can type into an AI agent that has shell access — so Prompter treats security as a feature, not an afterthought.

🔑

Token auth

A 256-bit token generated locally, stored with 0600 perms, sent in the Authorization header — never in URLs or logs.

🔒

No public ports

Remote access goes through your private Tailscale tailnet with WireGuard encryption. Nothing listens on the open internet.

♻️

One-command rotation

Delete the token file and restart — a fresh QR re-pairs the phone in seconds. Old tokens die instantly.

📦

Self-hosted, MIT

About 2 000 lines of readable Python and Kotlin. Audit it, fork it, ship your own. No accounts, no telemetry.
